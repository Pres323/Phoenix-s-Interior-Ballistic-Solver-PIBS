EMCC NFC WRITER

Writes an ID-only payload (emcc:card:N) to a blank NTAG213/215 sticker. All clinical data stays in the app's data/cards.json — never written to the tag.

Manual fallback

If Web NFC isn't available, write this exact payload using another NFC-writing app (e.g. NFC Tools):

emcc:card:1

Queues cards 1–49. Tap each blank tag when prompted; on a successful write it auto-advances to the next card.
